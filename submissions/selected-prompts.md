# Selected development prompts

The following prompts document the main requests used to build, verify, and prepare RoamReady for submission.

## Application implementation

> Do this assignment for me.

This request was accompanied by the Assignment 1 overview PDF. The resulting work created the separate Vue frontend and FastAPI backend, CSV search, SQLite persistence, booking CRUD, tests, setup documentation, and handoff notes.

## Submission reports

> Have a report.md file for me to send to Part 1 submission and Part 2 submission as well.

This produced separate `report.md` files using the required Part 1 and Part 2 heading structures.

## Repository checkpoint

> Commit the reviewed work, push it to GitHub and identify exact Part 1 commit.

This created the Git repository, published it to GitHub, and recorded the exact checkpoint links in the reports.

## Official course data

The official `hotels.csv`, `trips.csv`, `users.csv`, and `bookings.csv` files were supplied with their data guide and relationship diagram. The application was updated to preserve the text IDs, seed all four SQLite tables once, search by city or hotel, calculate stay prices, and manage booking dates and statuses.

## Verification evidence

> Add these into report md for Part 1.

> These are the needed files, put them into report md and push to GitHub.

These requests added the Boston and Miami search screenshots plus the initial, created, edited, and deleted booking-history screenshots to the repository and reports.
